# Explosive Biter Optimizations

Makes [Explosive Biters](https://mods.factorio.com/mod/Explosive_biters) cheaper to run by replacing nest/leviathan/boss death nukes with similar-looking blasts that skip the hundreds of atomic shockwave projectiles.

![Mod thumbnail](thumbnail.png)

**Requires:** Factorio 2.0, [Explosive Biters](https://mods.factorio.com/mod/Explosive_biters)

Startup settings tune optimization level, fire spread, and particles.

> This project is vibe-coded.
